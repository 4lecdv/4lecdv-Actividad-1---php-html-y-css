# 🏋️ Inscripción al Gimnasio

Formulario simple en HTML + PHP que calcula el precio del plan y sugiere una rutina según el objetivo del usuario.

**Alumno:** Alex Christian Dalesson

**Sitio web:** [gymactividad.gt.tc](http://gymactividad.gt.tc)

## Archivos

- `index.php` — formulario de inscripción
- `procesos.php` — procesa los datos y muestra el resultado
- `styles.css` — estilos

## Cómo correrlo

```bash
php -S localhost:8000
```

Abrí `http://localhost:8000/index.php`
